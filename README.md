# 💬 Real-Time Chat Application

This is a simple **real-time chat application** built using **HTML, CSS, JavaScript, and Socket.io**. Users can join the chat by entering their name and start chatting instantly.  

## 🚀 Features

- 🔥 **Real-Time Messaging** – Instant chat updates using Socket.io  
- 🏷️ **Username Selection** – Users can join by entering their name  
- 🎨 **Simple & Clean UI** – Minimalistic and easy-to-use interface  
- 👥 **Multiple Users Support** – Chat with multiple users in real time  
- 📱 **Fully Responsive** – Works on all devices (mobile, tablet, desktop)  

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **WebSockets:** Socket.io
